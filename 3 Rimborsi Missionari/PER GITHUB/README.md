# Rimborsi (Cassa Nazionale ADI)

Pagine statiche per preparare le richieste di rimborso spese. Nessun server, nessun dato online: tutto resta nel dispositivo di chi le usa.

- `/` scelta del profilo
- `/missionari/` Rimborsi Missionari
- `/pastori/` Rimborsi Pastori

Nessun dato dell'ufficio (registri, bollettini, richieste ricevute) va mai caricato in questo repository.
