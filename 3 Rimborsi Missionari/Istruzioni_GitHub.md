# Mettere online i Rimborsi (GitHub Pages)

Indirizzi finali:
- https://adi-cassa-nazionale.github.io/rimborsi/            (scelta profilo)
- https://adi-cassa-nazionale.github.io/rimborsi/missionari/
- https://adi-cassa-nazionale.github.io/rimborsi/pastori/

## 1. Rinomina il repository (una volta)
1. Apri github.com/adi-cassa-nazionale/rimborsi-missionari › Settings.
2. In «Repository name» scrivi `rimborsi` › Rename.
   (Il vecchio indirizzo `.../rimborsi-missionari/` smette di funzionare: va bene, non è ancora stato distribuito.)

## 2. Carica i file
1. Nel repository: Add file › Upload files.
2. Trascina TUTTO il contenuto della cartella `PER GITHUB` (anche le cartelle `missionari` e `pastori`).
3. Commit changes. Dopo 1-2 minuti i link sopra funzionano.
4. Se vedi la pagina vecchia: ricarica con Cmd+Maiusc+R.

## 3. File vecchi da togliere
Nella radice del repository, se presenti, elimina `sw.js` e `manifest.json` (ora stanno dentro `missionari` e `pastori`).
